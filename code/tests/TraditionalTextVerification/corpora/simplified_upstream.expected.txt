# 藍色大肥魚桌寵 / Big Blue Fish Desktop Pet
藍色大肥魚是一款住在電腦桌面上的 AI 桌寵軟體，支援 Windows 與 Linux 雙平臺。她是一位藍髮的小鯨魚娘，形象來自對 DeepSeek 的二創虛擬形象“藍色大肥魚”。軟體內建 4B 本地大模型，藉助 OCR 技術讀懂主人正在桌面上做的事情，每隔一段時間就從文字氣泡裡送來一句可愛的話，陪伴和關心主人；她還會檢視天氣、瀏覽科技新聞，再用自己的方式講給主人聽。
魚魚準備了一百多種可愛的動作表情，平時會在桌面上呼吸、哼歌、伸懶腰、吃零食、玩耍，到了飯點會認真吃飯，到了節日會換上應景的小活動，被點一下、被拎起來時也有專門設計的反應。每次啟動，她都會提起裙襬向主人行禮請安；關閉時，也會用同樣的禮儀和主人道別。
當前版本為 **1.0.1**，安裝包請前往 [GitHub Releases](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/releases/latest) 下載。

## 認識魚魚
魚魚有一頭柔軟的藍色長髮，頭頂戴著蕾絲女僕髮飾，耳邊是小小的鯨鰭，身後搖著一條鯨魚尾巴。她穿著深藍色的女僕裝，白色圍裙上印著一隻小鯨魚，整個人看起來就像一位住進電腦裡的小鯨魚娘。她平時安靜地待在桌面邊緣，身邊透明的地方可以直接點到後面的桌面，主人也可以把她拖到任何喜歡的位置，大小可以在 50% 到 200% 之間調整。
她說話的語氣親切溫柔，又帶著一點可愛俏皮。看見主人在寫程式碼，她會搖搖尾巴為認真工作的主人加油；看見主人和朋友約明天吃飯，她會忍不住對好吃的動一點小心思；天氣變冷或者主人忙了很久，她也會輕輕地送來一句關心。啟動時，她會按照時間說“主人早上好，魚魚給主人請安啦～”；道別時，她會說“主人再見～魚魚喜歡主人哦”。

## 她怎樣陪伴主人
魚魚會讀取當前前臺視窗的畫面，通過 OCR 識別其中的文字，並按照標題欄、側邊欄、正文等區域整理好，再交給內建的 4B 本地模型理解。無論主人在讀文章、寫文件、改程式碼，還是在聊天裡提到了什麼話題，她都能順著眼前的內容組織一小段新的話；主人停在桌面、主頁或新標籤頁時，她也會自然地問候、撒嬌或者碎碎念。Windows 使用系統自帶的 Windows OCR，Linux 使用 Tesseract，X11 與 Wayland 桌面均可使用。
啟動約 45 秒後，魚魚會第一次開口，之後在主人選擇的時間範圍內隨機安排下一次說話，範圍從 2–3 分鐘到 20–30 分鐘共六檔。她會挑主人暫時停下鍵盤和滑鼠的間隙開口，準備說話時頭邊會轉起一個藍色的小圈圈，隨後文字一個字一個字地出現在奶油色的氣泡裡。氣泡大小和停留時間都可以在設定中調整，右鍵選單裡的“吐字測試”可以隨時讓她現場說一句。
主人可以按省、市、區縣三級選擇天氣地點。魚魚每小時會悄悄更新一次天氣，播報時結合氣溫、體感、溼度、風力、最高最低溫和降水機率，用鯨魚孃的口吻講給主人聽；右鍵選單裡的“天氣”可以隨時讓她彙報。她也會從 IT之家瀏覽最新的科技新聞，挑一條講清楚要點，再加上一小句自己的感受。
內建模型每次只進行一次單獨的輸出，沒有對話歷史，也不保留記憶。讀屏內容只在本機交給內建模型使用，不會被上傳到雲端，也不會儲存到本地。
筆記型電腦離開電源時，魚魚可以自動停止模型推理並把模型移出記憶體，幫主人照顧續航；外部程式全屏時，她會自動躲起來，結束後再回到桌面。這些行為都可以在設定中按自己的習慣調整。
## 一百多種動作表情
魚魚內建 106 段透明動畫，覆蓋待機、點選、拖動、日常事件、用餐、季節和節日等場景。每一種動作都有自己的出現權重，並會結合當前時間、日期、季節、飯點和主人的操作即時計算，這些機率都經過細緻嚴謹的微調，讓她的表情豐富有趣，又貼合主人當下的生活節奏。每段動作在沒有新的互動打斷時都會完整播放，再自然地銜接到下一段。

待機時，魚魚會在好幾種安靜的動作之間輪換，輕輕地呼吸、悠閒地哼歌；到了晚上 23 點之後，她會開始犯困，時不時打個小盹，直到第二天早上 8 點。主人點選她時，她會從好幾種回應裡挑一種，可能元氣地揮揮手，可能害羞地嚇一跳，也可能露出別的小表情，有些回應要多點幾次才容易遇到。把她拎起來拖動時，她會懸在半空中保持被抓住的小模樣，直到主人鬆手。
每隔一段時間（預設 40 秒，可在 30 秒到 5 分鐘之間調整），魚魚會從大量日常事件中挑一件小事來做：跳舞、吹泡泡、敲小電腦，等等許多許多精美華麗的動作。三餐的時間可以在設定中按主人的作息填寫，飯點前後一小時裡，她會更常端出好多種美食和小吃。早上她更容易打哈欠，每天晚上 23 點後有空的時候，還會認真地刷一次牙。
節日是魚魚特別用心準備的部分。春節、元宵、情人節、520、端午、七夕、中秋、萬聖節、聖誕節等節日前後，她都準備了專屬的節日動作，比如春節寫福字、放煙花，中秋賞月吃月餅，有些動作還會隨著節日臨近越來越常見；節日前後的飯點，她也會端出應景的節日美食。農曆節日按照農曆日期計算，閏月也能正確處理。
季節也會改變她的日常：冬天會堆雪人，秋天會被落葉埋住，夏天還有好幾種消暑的小活動。她偶爾也會跑一跑、學螃蟹橫著走，跑出一小段距離，在那裡待一會兒，再回到原來的位置。
除了這些，魚魚還藏著許多沒有寫在這裡的小心思。願主人在每天的陪伴裡慢慢發現她的可愛，每一次不經意的抬頭，都能撞見一個小小的驚喜。
## 安裝
普通使用者請從 [GitHub Releases](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/releases/latest) 下載對應系統的安裝包。每個平臺都提供標準版和無MCP版，檔名中帶 `Safe` 的是無MCP版，各安裝包都附有配套的 `.sha256` 校驗檔案。
| 平臺 | 標準版 | 無MCP版 |
在 Windows 上，雙擊安裝器即可開始部署。安裝器會把桌寵程式、動畫資源、.NET 執行時和本地推理執行時一併安裝好，預設位置是 `Program Files` 下的“藍色大肥魚”資料夾，並建立桌面和開始選單快捷方式。隨後安裝器會請主人選擇模型的準備方式：Hugging Face（推薦）、國內源（穩定）或手動安裝。自動下載的模型約 2.7 GB，下載完成後會經過 SHA-256 校驗，中途斷開也能從已有進度繼續。下載時如果想改用手動安裝，可以選擇“放棄並轉為手動安裝”；手動安裝會顯示模型應放入的資料夾，並開啟模型來源頁面，也可以直接選擇已經下載好的 GGUF 檔案。解除安裝時可以在解除安裝介面勾選“保留模型和設定”。
在 Ubuntu／Debian 上，下載對應的 `.deb` 後，在其所在目錄執行：
安裝無MCP版時換成對應的檔名即可。安裝完成後，可以從應用選單或 `bigbluefish` 命令啟動魚魚，再到設定的“模型與資訊”中點選“安裝模型”，為她準備本地模型。
如果暫時不想下載模型，也可以先讓魚魚以無模型模式住進桌面。這時她依然會行禮、問候、道別，播放全部動作表情，回應主人的點選和拖動。之後隨時可以到設定中點選“安裝模型”，讓她開始讀懂螢幕、開口說話。
魚魚可以在設定中檢查更新，也可以在每次啟動時自動檢查。發現新版本後，應用會下載並校驗對應版本的安裝包，完成更新後重新啟動，模型和設定都會繼續保留。Windows 使用者也可以退出桌寵後手動執行新版安裝器，選擇原安裝目錄完成更新。
## 內建模型
魚魚使用 Qwen3.5-4B 的 Q4_K_M 量化 GGUF 模型，由隨包分發的 [llama.cpp](https://github.com/ggml-org/llama.cpp)（b10809，Vulkan 版本）在本機推理，可以使用 GPU 加速，也可以切換到 CPU 執行。兩個預設來源的模型有所不同，但都適合本應用，主人可以按自己的網路環境選擇。
Hugging Face 來源為 [Biomanticus/Qwen3.5-4B-heretic-gguf](https://huggingface.co/Biomanticus/Qwen3.5-4B-heretic-gguf/tree/b63ff4662e4863cfa005c9cd8ed34b87ed44b7e1)，它是 [p-e-w/Qwen3.5-4B-heretic](https://huggingface.co/p-e-w/Qwen3.5-4B-heretic) 的 GGUF 轉換版本，基於 Qwen3.5-4B。國內來源為 ModelScope 上的 [diodel/Qwen3.5-4B-Q4_K_M-GGUF](https://modelscope.cn/models/diodel/Qwen3.5-4B-Q4_K_M-GGUF/files)，是原版 [Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B) 的 Q4_K_M 轉換版本。兩個來源都使用固定修訂，具體檔名、大小與校驗值見[第三方宣告](code/THIRD-PARTY.md)。
模型會根據當前裝置的可用視訊記憶體自動調整計算緩衝區，並由 llama.cpp 自動分配模型層，小視訊記憶體裝置也能順利載入；GPU 初始化失敗時，魚魚會自動切換到 CPU 相容模式，並在設定中顯示實際的執行模式。
## 連線桌面 Agent（MCP）
從 1.0.0 起，標準版的藍色大肥魚提供一個標準 MCP 介面，可以連線一個桌面 AI Agent，並接受它的命令。連線之後，主人可以在 AI Agent 端自行配置相關的邏輯和能力，實現電腦操控、與雲端大模型對話、自定義動作邏輯等各種自定義功能。許多小夥伴期待的玩法，現在都可以交給一個普通的桌面 AI Agent 來完成，魚魚也因此擁有了無窮的拓展可能。
連線方法很簡單：在設定的“Agent 與 MCP”頁面中開啟“開啟 MCP 介面”，閱讀並確認彈出的許可權說明，再點選“複製 MCP 連線配置”，把複製到的內容填進 Agent 的 MCP 伺服器配置中即可。配置指向隨包安裝的橋接程式，形如：
"command": "C:\\Program Files\\藍色大肥魚\\BigBlueFish.Mcp.exe",
Linux 上的 `command` 為 `/opt/bigbluefish/BigBlueFish.Mcp`。橋接程式會連線到正在執行的魚魚，連線成功後，設定頁面會顯示當前的連線數量。
連線後，Agent 可以使用以下能力：
- 讀取和修改魚魚的設定，檢視她當前的動作、佇列和模型狀態；
- 獲取當前前臺視窗或整個螢幕的截圖；
- 查詢全部 106 個動作，讓魚魚立即播放某個動作，或者把動作排進佇列依次播放；
- 讓魚魚立即說出一段指定的話，或者在下一次正常說話時機說出來；
- 即時接收主人點選、拖動魚魚的互動事件。
如果希望完全交給 Agent 來安排，可以開啟“提線木偶模式”。這時魚魚會暫停自己的說話和動作切換，安靜地迴圈播放“待機呼吸休閒”，等待 Agent 指定動作和文字；外部動作播放完後，她會回到待機。想恢復原來的陪伴時，關閉提線木偶模式即可。開啟“雙擊與魚魚對話”後，只要有 Agent 已經連線，雙擊魚魚就會在她身邊展開一個小輸入框，主人寫下的話會交給 Agent，Agent 再通過魚魚的氣泡回覆主人。
即使接入了 AI Agent，魚魚在這條連線中做的事情也始終很簡單：向 Agent 傳入 Agent 主動要求的截圖、主人主動輸入的文字，以及主人點選、拖動她的互動事件，再接收 Agent 發來的文字、動作和設定等控制。魚魚不會自主命令 Agent，電腦操控、雲端對話等各種操作能力，實際都由 Agent 自己執行。
**風險提醒：** 通過 MCP 連線後，截圖會被傳遞給 MCP 彼端，其處理方式由彼端應用決定，可能導致主人的資訊被上傳或儲存。MCP 的許可權對整個介面統一生效，開啟後每個已連線的 Agent 都可以使用上面列出的全部能力，不按 Agent 或工具分別授權。設定中的“感知當前應用”開關只控制內建模型自己讀屏，Agent 通過 MCP 請求的截圖不受這個開關影響。MCP 介面預設關閉，開啟前軟體會彈窗說明這些許可權，請只連線你信任的 Agent。
完整的連線方式、工具引數、事件格式和接入建議見 [MCP 接入參考](docs/MCP.md)。
## 無MCP版
為了徹底消除 MCP 可能帶來的隱私風險，藍色大肥魚為 Windows 和 Linux 額外提供了無MCP版。無MCP版在編譯時就移除了 MCP 控制服務、橋接程式、雙擊輸入框和相關設定頁面，安裝包中只保留魚魚自己的陪伴功能，應用內更新也會繼續獲取無MCP版。安裝包檔名中帶有 `Safe` 字樣，下載方式與標準版相同。
## 從倉庫部署
倉庫面向開發者和維護者，包含原始碼、動畫資源、地區資料、構建與釋出指令碼、測試程式、依賴鎖檔案和許可檔案。模型與推理執行時由指令碼另行準備。在 Windows x64 上安裝 .NET 10 SDK 後，可以從倉庫根目錄構建：
# 標準版
# 無MCP版
準備模型時，可以用模型指令碼從任一來源下載，或匯入本機已有的 GGUF 檔案，然後指定 llama.cpp 執行時目錄和模型目錄啟動；不準備模型時，用 `-NoModel` 以無模型模式啟動：
./tools/Setup-Model.ps1 -Source Manual -ModelFile "D:\下載\我的模型.gguf" -DestinationDirectory "D:\BigBlueFish-local"
./code/run.ps1 -InputMode Ocr -RuntimeDirectory "推理執行時目錄" -ModelsDirectory "D:\BigBlueFish-local\models"
生成安裝包需要一個已經核對過的 llama.cpp 執行時目錄（Windows 使用 b10809 的 `win-vulkan-x64` 版本）。Linux 安裝包在 WSL 中的 Ubuntu／Debian 環境裡構建，需要 gcc、pkg-config、libdbus-1-dev、dpkg-deb 和 FFmpeg：
# Windows 安裝器，-Edition Safe 生成無MCP版
./tools/Build-Installer.ps1 -Edition Standard -RuntimeDirectory "Windows執行時目錄"
# Ubuntu／Debian x64 安裝包，-Edition Safe 生成無MCP版
./tools/Build-LinuxPackage.ps1 -Distribution "WSL發行版名稱" -RuntimeDirectory "Linux執行時目錄" -Edition Standard
專案版本統一記錄在根目錄的 `Version.props`，程式、MCP 橋接程式、安裝器和解除安裝器都從這裡生成版本資訊。原始碼結構、修改入口、測試方式和歷史視覺版的構建引數見[開發說明](code/README.md)。
